# Areca

A cross-platform networking and communication application.

Areca is a project that explores private networking, secure communications, distributed systems and real-time data transfer.

## Project Goals

- Private networking between devices
- Secure messaging using encryption
- File and image transfer
- Voice and video communication
- Cross-platform support
- Modular networking and security architecture
- Explore post-quantum cryptography with later modular applicaion

## Planned Technologies

- Go — core for networking and backend
- C++ — future performance-oriented components
- TypeScript / React — application interface
- ______ - transport protocol (will be mentioned later in project)
- PostgreSQL (possible change later...) — application data storage
